# React Projects

A collection of React and TypeScript projects built to strengthen my
frontend development skills through practical, hands-on applications.

Rather than focusing only on tutorials, this repository contains
projects in which I apply React concepts to realistic use cases such as
API integration, state management, user interaction and data
transformation.

## Purpose

The goal of this repository is to develop a deeper understanding of
modern React development and gradually build more complex applications.

The projects focus on topics such as:

-   React component architecture
-   TypeScript
-   Typed props and callbacks
-   State management with `useState`
-   Side effects with `useEffect`
-   REST API integration
-   `fetch`, Promises and `async/await`
-   Loading, error and empty states
-   Conditional rendering
-   Array methods such as `.map()`, `.filter()`, `.find()` and
    `.reduce()`
-   Component communication
-   Responsive UI development
-   Code structure and separation of concerns

As the repository grows, I will also explore more advanced concepts such
as custom hooks, routing, testing and more complex state management.

### 🛒 Smart Grocery Planner

A React + TypeScript grocery planning application that retrieves
products from an external API and allows users to create a shopping
list.

**Features**

-   Fetches products from an external REST API
-   Search and filter products
-   Add products to a shopping list
-   Automatically manage product quantities
-   Calculate line prices and total price
-   Loading state
-   Error handling
-   Empty states
-   Typed React components
-   Responsive interface

**Main concepts**

`React` · `TypeScript` · `useState` · `useEffect` · `Fetch API` ·
`async/await` · `Props` · `Callbacks` · `CSS Grid`

➡️ See the project folder for the full technical README.

## 🧠 Learning approach 🧠

For each project I aim to understand not only **how** something works,
but also **why** it is implemented that way.

The general workflow is:

``` text
Concept
   ↓
Small implementation
   ↓
Understand the data flow
   ↓
Add TypeScript
   ↓
Handle edge cases
   ↓
Refactor into components
   ↓
Improve the UI
   ↓
Review and document
```

This allows the projects to evolve from small exercises into complete
frontend applications.
